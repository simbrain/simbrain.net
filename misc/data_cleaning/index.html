Instructions
  1. Data cleaning. Remove the rows with missing or garbled categorical data.
  2. Imputation. Replace the missing or bad numbers with the average of the rest of their column. Bad numbers include text (like NA, ?, or a number written in words), a value that is zero or negative, and a number off by orders of magnitude (like 99999 g).
  3. Rescaling. Rescale any numeric column with values above 1 by dividing by its maximum.
  4. Feature engineering. Replace each column of categories (text values) with one-hot columns.
  5. Make two new tabs, named “inputs” and “targets”. Copy the input features into “inputs” and the one-hot fruit columns into “targets”.
  6. Train a classifier in Simbrain to predict the fruit.
Spreadsheet formulas

These assume the data runs from row 2 to row 35, with the column names in row 1. Adjust the letters and row numbers to match your sheet.

Impute a cell. To fill a blank, for example C12, with the average of the cells above and below it, type =AVERAGE(C2:C11, C13:C35).

Rescale. In an empty column, type =A2/MAX(A:A), replacing A with the column you are rescaling, and fill down.

Copy a column. To copy column B into an empty column, type =B2 in row 2 of the empty column and fill down. The copy updates if the original changes.

One-hot. Type the category names (apple, orange, lemon) as column names in row 1 of three empty columns, for example G, H, I. In G2 type =IF($D2=G$1,1,0) and fill down and across.

One-hot by hand. You can also type the 1s and 0s yourself. Type the category names in row 1 as above, then type 0 in G2. Drag it across to I2, then select G2:I2 and drag down to the last row, so every cell is 0. Then go down the rows one at a time and change the 0 under the matching fruit to 1.
